## MuseJazz Text

Jazz Chart Viewer prefers the **MuseJazz Text** font from the MuseScore project. The application first checks for a locally installed copy and otherwise requests the unmodified font from a pinned MuseScore repository revision through jsDelivr. The pinned upstream revision is `c1ad658dec3f29ef7e089a5915c7eed91a7e5349`; the original font and license are maintained in the MuseScore MuseJazz font directory.

Copyright © 2016, Torsten Hämmerle and Abraham Lee (Music Type Foundry).

MuseJazz Text is licensed under the **SIL Open Font License, Version 1.1**. The copyright notice and complete license text are included in [`licenses/MuseJazzText-OFL-1.1.txt`](licenses/MuseJazzText-OFL-1.1.txt).

The font binary itself is not part of this static distribution. If the font cannot be loaded, Jazz Chart Viewer substitutes standard Unicode symbols so chord names remain readable.
