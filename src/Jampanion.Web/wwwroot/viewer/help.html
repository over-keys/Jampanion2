Jampanion2

iReal形式のジャズ・コード譜を表示し、ピアノ・ベース・ドラムの伴奏に合わせて練習・演奏できるアプリです。コードやリハーサルマークの編集、移調、リピート展開など、Jampanion2を使うために必要な操作をまとめています。

伴奏と譜面編集

Jampanion2では、譜面を読むだけでなく、コード進行に合わせたピアノ・ベース・ドラムの伴奏をブラウザで再生できます。まず曲をインポートして選び、画面左のAccompanimentとSessionを使います。

最初の演奏

  1. 曲を選び、キー、Original / Expanded、テンポ、スタイルを確認します。
  2. Tempoを入力し、StyleでSwing / Ballad / Bossa Nova / Latinを選びます。4/4以外の曲では対応するスタイルだけが表示されます。
  3. Start sessionを押すとカウントインの後に演奏が始まります。演奏中は譜面が現在位置へ自動スクロールします。
  4. すぐに演奏を止めるときはStopを押します。再生中のノートオフも同時に送られます。
  5. テーマに戻って自然に終わらせるときは、演奏中のBack to headを押します。Head Outがキューされ、現在の区切りからテーマに戻って演奏したあと、曲が終了します。キューされるとボタンはHead out queuedに変わります。
StopとHead Outの違いStopはその場で伴奏を止めます。Head Outは演奏をすぐには止めず、テーマに戻る流れをキューしてから終了します。

テンポ、スタイル、保存

Tempo上下操作は5 BPMずつ変わります。数値を直接入力すれば、1 BPM単位の値も指定できます。
StyleSwing、Ballad、Bossa Nova、Latinから伴奏スタイルを選びます。リハーサルマークごとに別のスタイルも指定できます。
Save / RevertSaveはコード、リハーサルマーク、移調したキー、テンポ、スタイルの変更をまとめて保存します。Saveを押すまでは一時的な変更です。Revertは保存したキー、テンポ、スタイルを元に戻し、インポート元を残した編集版の曲では元のiReal譜面にも戻します。
Key−／＋で変更した移調キーも、Saveで曲ごとに保存され、次回自動復元されます。
演奏中の変更スタイル変更は次の4小節区切り、テンポ変更は次の小節区切りから適用されます。

コードとリハーサルマークを編集する

  • コードをダブルクリックして編集します。入力を空にして確定すると、そのコードを削除します。
  • 小節内の空いている場所をダブルクリックすると、その拍位置にコードを追加できます。
  • マークのない行の左側をダブルクリックしてリハーサルマークを追加し、既存のマークをダブルクリックして名前を変更します。入力を空にして確定すると削除できます。
  • リハーサルマークまたはその小節を右クリックすると、セクションスタイルだけを指定できます。
  • スタイルを指定したリハーサルマークの上には、Swing / Latin / Bossa / Balladが表示されます。曲のデフォルトを使う場合は表示されません。
  • タイトルもダブルクリックで変更できます。
編集内容の保存編集したコードやマークは、Accompaniment欄のSaveで保存します。曲を閉じたり別の曲を選ぶ前にSaveを押してください。最初に編集すると、インポート元を残したまま、このブラウザで編集できる曲として保存されます。

MixとMIDI

  • MixでPiano、Bass、Drumsの音量とミュートを調整できます。設定は曲を閉じても同じブラウザに保存されます。
  • Settings → Audio & MIDIでMIDI inputとMIDI outputを選べます。外部MIDI出力がない場合も、Built-in Trioでブラウザ音源を使えます。
  • MIDI thruを有効にすると、選択したMIDI inputのノートを出力先へ中継できます。
スマートフォンでは、Sessionの操作を上部に残し、譜面を縦にスクロールして使います。Mixは譜面の下にあります。

まず使ってみる

  1. 歯車ボタンを開き、Import iReal dataを選びます。
  2. iRealの共有リンクを貼り付けるか、保存済みのテキスト／HTMLファイルを選び、Importを押します。
  3. 検索欄から曲を選びます。
  4. − / +でキーを変更し、Auto / ♭ / ♯で表記を選びます。
  5. 譜面どおりに読む場合はOriginal、演奏順に展開して読む場合はExpandedを選びます。

曲をインポートする

Jazz 1460をインポートする

iReal Pro公式コミュニティフォーラムのトピックを開き、最初の投稿にあるJazz 1460リンクを探します。

Jazz 1460のトピックを開く
  1. Jazz 1460というリンクそのものをコピーします。ブラウザ上部のページURLではありません。
  2. パソコンではリンクを右クリックしてリンクのアドレスをコピーまたはリンクをコピーを選びます。スマートフォン／タブレットではChromeでリンクを長押しし、リンクをコピーを選びます。Safariではコピーできないため、Chromeまたはパソコンを使ってください。
  3. コピーした文字列がirealb://またはirealbook://で始まることを確認します。
  4. ビューアーで設定 → Import iReal dataを開き、貼り付けてImportを押します。
以前の全曲集を置き換える場合は、先にDelete all songsを実行すると、削除・改名された古い譜面が残りません。

その他のiRealデータ

irealb://またはirealbook://で始まる共有リンクを貼り付けるほか、保存済みの.txt、.html、.htmファイルも選択できます。

新しいインポートは現在のライブラリへ追加されます。同じ曲名・作曲者の譜面は新しい内容で置き換わり、その他の曲は残ります。

曲を検索して選ぶ

検索欄では、インポート済みの曲を曲名または作曲者名で検索できます。候補は先頭100件まで表示されます。マウスまたはタッチで選択し、キーボードでは↑ / ↓で候補を移動、Enterで決定、Escapeで閉じます。

別の曲を選んだとき一時的な移調は解除され、選択した曲の原調へ戻ります。

キーと異名同音表記を変更する

− / +表示中のキーとすべてのコードを半音ずつ下げる／上げる。
Auto移調後のキーに応じて、フラット系またはシャープ系の表記を自動選択する。
♭B♭、E♭など、フラット表記を優先する。
♯F♯、C♯など、シャープ表記を優先する。

移調は表示だけに適用されます。インポート済みの元譜データは変更されません。

OriginalとExpanded

Original

リピート記号、1番・2番カッコ、D.C.、D.S.、Fine、Segno、To Coda、Codaなどを含め、譜面に記載された形のまま表示します。

Expanded

譜面上のナビゲーションを、上から下へそのまま読める演奏順へ展開します。

Expandedではリピートと番号付きカッコを展開し、対応しているD.C.／D.S.は、記載されたFineまたはCodaまでたどります。展開後はリピートの点やカッコを除去しますが、音楽的なセクション境界は複縦線として残します。

Originalを基準に確認してくださいExpandedは、インポートされた譜面のナビゲーションを標準的な規則で解釈する補助表示です。特殊な文章指示や不完全なリピート情報を含む場合は、Originalと比較し、Originalを正として確認してください。

譜面の大きさと画面表示

Scaleスライダー譜面の大きさを手動で設定し、Fitを解除する。
Fit画面に収まる大きさへ再調整する。
Fullscreenデスクトップの対応ブラウザで全画面表示を開始・終了する。スマートフォンでは表示されない。

スマートフォンを含め、基本的に1行4小節を保ったまま、画面幅に合わせて全体を縮尺します。元譜に含まれる拍子変更、リハーサルマーク、複縦線、リピート、カッコ、Segno、Coda、終止線も表示します。

設定

歯車ボタンから、次の操作ができます。

  • メジャー、マイナー、ハーフディミニッシュ、ディミニッシュの表記変更
  • iRealデータの追加インポート
  • インポート済み全曲の削除

Delete all songsはインポート済みの曲を削除しますが、内蔵のデモ譜面は残ります。

保存場所とプライバシー

本アプリは、ユーザーが選択したコード譜データをブラウザ内で解析・表示します。インポートしたデータは運営者のサーバーには送信されません。インポートするデータを利用する権限があることは、ユーザー自身の責任で確認してください。

曲と表示設定は、現在開いているサイト専用のブラウザ内に保存されます。

ブラウザデータを削除した場合、別のブラウザや端末を使う場合、サイトのドメイン名やリポジトリのパスが変わった場合は、曲を再インポートしてください。プライベートブラウズでは、セッション終了時にライブラリが消えることがあります。

MuseJazz Textフォント （任意）

通常は自動で読み込まれます。ローカルにインストールする場合は次の手順です。

  1. MuseJazzText.otfをダウンロードします。
  2. Windowsではファイルを開いてインストール、macOSではフォントをインストールを選びます。Linuxでは~/.local/share/fonts/へコピーし、fc-cache -fを実行します。
  3. ブラウザを再起動します。

フォントを読み込めない場合は、通常の△記号で表示します。
