Jampanion2

Jampanion2 displays iReal-format jazz chord charts and lets you practice or play along with piano, bass, and drums. This guide covers accompaniment, chart editing, importing songs, transposition, and repeat expansion.

Accompaniment and chart editing

Jampanion2 is more than a chart viewer: it plays piano, bass, and drums along with your chord progression. Select a song, then use Accompaniment and Session.

Starting a session

  1. Select a song and check the key, Original / Expanded view, tempo, and style.
  2. Enter the Tempo and choose Swing / Ballad / Bossa Nova / Latin in Style. Only styles supported by the meter are shown.
  3. Press Start session to begin after the count-in. The chart scrolls to the current position during playback.
  4. Press Stop to stop immediately. It also sends note-off messages for playing notes.
  5. To finish naturally, press Back to head while playing. Head Out is queued; the accompaniment returns to the theme at the next suitable boundary, plays the theme through, and then ends. The button changes to Head out queued while queued.
Stop vs Head OutStop stops the accompaniment where it is. Head Out keeps playback running, queues the return to the theme, and ends after the theme is played.

Tempo, style, and saving

TempoThe stepper buttons change the tempo by 5 BPM. You can enter any whole-number BPM directly.
StyleChoose Swing, Ballad, Bossa Nova, or Latin. You can assign a different style to each rehearsal mark.
Save / RevertSave stores chart edits, rehearsal marks, the transposed key, tempo, and style changes together. Changes remain temporary until you press Save. Revert resets saved key, tempo, and style settings; for an edited song that keeps its imported source, it also restores the original iReal chart.
KeyThe transposition made with − / + is also saved per song when you press Save and restored next time.
Changes during playbackStyle changes take effect at the next four-bar boundary. Tempo changes take effect at the next bar boundary.

Editing chords and rehearsal marks

  • Double-click a chord to edit it. Confirm an empty value to remove it.
  • Double-click an empty position in a bar to add a chord at that beat.
  • Double-click the left side of a row without a mark to add a rehearsal mark. Double-click an existing mark to rename it. Confirm an empty value to remove it.
  • Right-click a rehearsal mark or its bar to assign a section style only.
  • Assigned styles appear above rehearsal marks as Swing / Latin / Bossa / Ballad. The label is hidden when the song default is used.
  • Double-click the title to rename the song.
Saving editsPress Save in Accompaniment to keep edited chords and marks. Save before closing or changing songs.

Mix and MIDI

  • Use Mix to adjust Piano, Bass, and Drums volume or mute state. These settings are remembered in the same browser.
  • Open Settings → Audio & MIDI to choose MIDI input and MIDI output. Choose Built-in Trio to use the browser instruments when no external MIDI output is available.
  • Enable MIDI thru to relay notes from the selected MIDI input to the output.
On smartphonesSession controls stay at the top while the chart scrolls vertically. Mix is below the chart.

Quick start

  1. Open the gear button and choose Import iReal data.
  2. Paste an iReal shared link or choose a saved text or HTML file, then select Import.
  3. Choose a song from the search box.
  4. Use − / + to change key, and Auto / ♭ / ♯ to control spelling.
  5. Use Original for the written chart or Expanded for linear performance order.

Import songs

Import Jazz 1460

Open the official iReal Pro community forum topic and find the Jazz 1460 link in the first post.

Open Jazz 1460 forum topic
  1. Copy the Jazz 1460 link itself. Do not copy the browser's page address.
  2. On a computer, right-click the link and choose Copy link address or Copy Link. On a phone or tablet, use Chrome: touch and hold the link and choose Copy link. Safari cannot copy this link, so use Chrome or a computer.
  3. Confirm that the copied text begins with irealb:// or irealbook://.
  4. In Jampanion2, open Settings → Import iReal data, paste the link, and select Import.
Replacing an older full playlist: use Delete all songs first so obsolete or renamed charts do not remain.

Import other iReal data

You can paste any irealb:// or irealbook:// shared link, or choose a saved .txt, .html, or .htm file.

Imports are merged with the current library. A chart with the same title and composer replaces the existing copy; other songs remain.

Find and select a song

Search imported songs by title or composer. Only the first 100 matches are shown. Choose a result with the mouse or touch. With a keyboard, use Up / Down to move, Enter to select, and Escape to close the list.

When you change songsThe temporary transposition resets to the selected song's original key.

Change key and note spelling

− / +Transpose the displayed key and every chord down or up by one semitone.
AutoChoose flats or sharps according to the transposed key.
♭Prefer flat spellings, such as B♭ and E♭.
♯Prefer sharp spellings, such as F♯ and C♯.

Transposition affects only the displayed chart. The imported source data is not modified.

Original and Expanded views

Original

Shows the chart as written, including repeat signs, first and second endings, D.C., D.S., Fine, Segno, To Coda, and Coda markings.

Expanded

Turns the navigation into a linear top-to-bottom sequence that can be read in performance order.

Expanded view resolves written repeats and numbered endings. Supported D.C. and D.S. instructions are followed through Fine or Coda when those markings are present. Repeat dots and ending brackets are removed from the expanded sequence, while musical section boundaries remain visible as double barlines.

Use Original as the referenceExpanded view follows standard navigation rules encoded in the imported chart. If a source uses unusual text instructions or malformed repeat data, compare it with Original and treat Original as authoritative.

Size and screen controls

Scale sliderSets a manual chart size and turns Fit off.
FitFits the chart to the available viewport again.
FullscreenEnters or exits fullscreen in supported desktop browsers. It is hidden on smartphones.

The layout keeps four measures per row, including on mobile screens, and scales the whole page to fit. Time-signature changes, rehearsal marks, double barlines, repeats, endings, Segno, Coda, and final barlines are preserved where present in the source chart.

Settings

Open the gear button to:

  • choose the display style for major, minor, half-diminished, and diminished chords;
  • import more iReal data;
  • delete all imported songs;

Delete all songs removes the imported library but leaves the built-in demonstration chart.

Local storage and privacy

This application imports and displays chord-chart data selected by the user. Imported data is processed locally in the browser and is not uploaded to the application operator. Users are responsible for ensuring that they have the right to use the imported content.

Songs are stored locally in IndexedDB for the exact site URL, while display settings are stored in localStorage for that URL.

Re-import songs after clearing browser data, changing browser or device, or opening the viewer at a different domain or repository path. Private or incognito mode may discard the library when the private session ends.

MuseJazz Text font (optional)

The viewer tries to load MuseJazz Text automatically. To install it locally:

  1. Download MuseJazzText.otf.
  2. Open it and choose Install on Windows or Install Font on macOS. On Linux, copy it to ~/.local/share/fonts/ and run fc-cache -f.
  3. Restart the browser.

If the font is unavailable, the viewer uses the standard △ symbol instead.

Troubleshooting

The import says no iReal data was found.
Confirm that the pasted text begins with irealb:// or irealbook:// and was not truncated.
The pasted text begins with https://forums.irealpro.com/.
You copied the forum page address. Copy the Jazz 1460 link itself.
Selecting Jazz 1460 opens iReal Pro.
In Chrome, touch and hold the link and choose Copy link. Safari cannot copy this link.
Imported songs disappeared.
Browser data may have been cleared, or the site's URL changed. Import the playlist again.
The chart is too small or too large.
Select Fit, or move the Scale slider to set a manual size.
Expanded order looks wrong.
Compare with Original and check whether the source chart uses nonstandard or incomplete navigation markings.
The major symbol looks different.
Install MuseJazz Text, or continue using the standard △ fallback.
